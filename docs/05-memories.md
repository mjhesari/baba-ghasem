# خاطرات

خاطرات در `content/memories.ts` هستند و در `/memories` خوانده می‌شوند. اگر آرایه خالی باشد، صفحه جملهٔ خالی خودش را نشان می‌دهد. اولین خاطرهٔ آرایه روی صفحهٔ خانه، زیر عنوان «خاطره‌ای از خانه»، هم می‌آید. این انتخاب در `app/page.tsx` است.

## خاطرهٔ واقعی

نمونهٔ فعلی را جایگزین کن یا یکی تازه اضافه کن:

```ts
{
  slug: "pish-az-khab",
  name: "نام شخص",
  relation: "نوه",
  sample: false,
  text: "متن خاطره، همان‌طور که گفته شده.",
  image: "/images/memories/ali.jpg",
  imageAlt: "توضیح عکس",
}
```

عکس را فقط وقتی بگذار که فایل، عکس واقعی خانواده باشد. مسیر فایل: `public/images/memories/`. در داده، همان مسیر با پیشوند `/images/...` نوشته می‌شود.

اگر `sample` برابر `true` باشد، بالای خاطره نوشته می‌شود «نمونه · در انتظار خاطرهٔ خانواده». برای خاطرهٔ واقعی `sample` را `false` بگذار یا حذف کن.

`relation` نسبت آدم با شاعر است، مثلاً فرزند یا نوه. اسم و نسبت زیر نقل‌قول می‌آیند.

صفحهٔ نمایش `app/memories/page.tsx` است. اگر چیدمان نقل‌قول را می‌خواهی عوض کنی، همان فایل است، نه فایل داده.
