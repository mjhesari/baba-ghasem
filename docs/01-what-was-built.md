# چه چیزی ساخته شد

پروژه در شروع یک قالب خام Next.js 16 بود: App Router، React، TypeScript و Tailwind CSS 4. صفحهٔ پیش‌فرض سازنده، فونت لاتین، و هیچ محتوا یا کامپوننتی نداشت. پایگاه‌داده هم نبود. همان پایه نگه داشته شد و دفتر روی آن ساخته شد.

دو بسته اضافه شد:

- `motion` برای محو شدن صفحه، آشکار شدن بخش‌ها، و جابه‌جایی خیلی کم قهرمان صفحه
- `lucide-react` برای آیکون‌ها

فونت رابط Vazirmatn است و فونت شعر و عنوان‌ها Amiri. هر دو با `next/font` بارگذاری می‌شوند. جهت سایت راست‌به‌چپ است و زبان صفحه فارسی.

## صفحه‌ها

| مسیر | نقش |
| --- | --- |
| `/` | خانه: نام شاعر، جملهٔ کوتاه، شعر امروز، فهرست کوتاه، راه دست‌نوشته و خاطره |
| `/poems` | فهرست دیوان، با پالایش قالب و حال‌وهوا |
| `/poems/[slug]` | صفحهٔ مستقل هر شعر |
| `/manuscripts` | آرشیو دست‌نوشته، با بزرگ‌نمایی |
| `/about` | زندگی شاعر: خط زمان و ردپای مکان‌ها |
| `/memories` | خاطرات خانواده |
| `/media` | صدا، فیلم و عکس |
| `/search` | جستجو در عنوان، متن، قالب و سال |

صفحهٔ گم‌شده هم با زبان خود دفتر است، نه صفحهٔ پیش‌فرض Next.js.

## داده

شعر، دست‌نوشته، خاطره، رویداد زندگی، مکان و رسانه در پوشهٔ `content/` به‌صورت TypeScript نگه داشته می‌شوند. خواندن آن‌ها از `lib/poems.ts` و `lib/content.ts` می‌گذرد تا بعداً انتقال به پایگاه‌داده فقط همان لایه را عوض کند.

چون شعر، عکس و تاریخ واقعی در پروژه نبود:

- هشت شعر نمونه برای دیدن حروف‌چینی گذاشته شد و رویشان «نمونهٔ حروف‌چینی» دیده می‌شود.
- قاب دست‌نوشته خالی است و روی خودش نوشته شده که عکس یا خط واقعی نیست.
- خط زمان و ردپا یک جایگاه خالی‌اند، بدون تاریخ یا شهر ساختگی.

تا وقتی فیلد `sample` یک شعر `false` نشود، آن شعر در `sitemap` نمی‌آید و متای `noindex` دارد.

## اجرا

```bash
npm run dev
npm run lint
npm run build
```

`npm run lint` و `npm run build` روی همین نسخه بدون خطا تمام شده‌اند.
