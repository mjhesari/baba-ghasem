# زندگی شاعر و ردپا

هر دو روی `/about` هستند. معرفی بالای صفحه در `app/about/page.tsx` است.

## خط زمان

رویدادها در `content/life-events.ts` هستند. ترتیب آرایه، ترتیب خط از بالا به پایین است.

```ts
{
  slug: "tavalod",
  yearLabel: "۱۳۲۰",
  title: "تولد",
  body: "آنچه خانواده از این سال به یاد دارد.",
  image: "/images/author/young.jpg",
  imageAlt: "توضیح عکس",
  poemSlug: "cheragh",
  sample: false,
}
```

`yearLabel` متن نمایشی است، پس عدد فارسی را خودت بنویس. تاریخ را وقتی بگذار که خانواده همان را گفته باشد.

`poemSlug` اختیاری است و به صفحهٔ همان شعر پیوند می‌دهد.

`sample: true` برچسب «جایگاه خالی · در انتظار روایت خانواده» را نشان می‌دهد. رویداد واقعی این فیلد را `false` دارد یا اصلاً ندارد.

عکس زندگی را در `public/images/author/` بگذار.

نشانه‌های خط زمان (خط کنار متن و لوزی کوچک) در کلاس `.timeline` داخل `app/globals.css` است.

## ردپای شاعر

مکان‌ها در `content/places.ts` هستند و پایین همان صفحهٔ درباره، بخش «ردپای شاعر»، دیده می‌شوند.

```ts
{
  slug: "mashhad",
  name: "مشهد",
  note: "چرا این مکان در زندگی او مهم بوده.",
  poemSlugs: ["cheragh", "bahar"],
  placeholder: false,
}
```

`poemSlugs` فهرست شعرهای مربوط به همان مکان است. هر مقدار باید `slug` یک شعر واقعی باشد.

`placeholder: true` یعنی نام مکان هنوز از خانواده نرسیده و صفحه آن را جایگاه خالی نشان می‌دهد. برای مکان معلوم، `placeholder` را `false` بگذار.

شهر را فقط وقتی بنویس که جزو زندگی او باشد. جایگاه خالی فعلی عمداً نام شهری ندارد.
